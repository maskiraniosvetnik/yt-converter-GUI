# YT2MP4 USB Converter

A small Linux GUI tool for downloading and conversion of a youtube video to mp4 or mp3 using `yt-dlp` and `ffmpeg`.

## installation

On Debian based:

```bash
sudo apt install python3 python3-tk yt-dlp ffmpeg
```
On Arch based

```bash
yay python3 python3-tk yt-dlp ffmpeg
```

or simply run:

```bash
chmod +x install.sh run.sh
./install.sh
```

## how to run?

```bash
./run.sh
```
## hint
you can make a desktop shortcut so you don't waste too muchtime.

## How to use it

1. Paste an URL.
2. Choose a folder.
3. Choose video quality: best, 1080p, 720p, 480p or audio-only-mp3.
4. click `Download / Convert to MP4`.
